# Enterprise Windows Server Administration Lab

## Overview

This repository documents my hands-on implementation of an Enterprise Windows Server Administration environment deployed in a virtual lab. The project was designed to simulate a real-world enterprise infrastructure, allowing me to gain practical experience in deploying, configuring, administering, and troubleshooting core Windows Server services.

As part of this project, I installed and configured Windows Server, promoted the server to an Active Directory Domain Controller, and built a complete Active Directory Domain Services (AD DS) environment. I configured DNS and DHCP services, created Organizational Units (OUs), managed users, groups, and computer accounts, joined Windows client systems to the domain, and implemented Group Policy Objects (GPOs) to manage security and administrative settings.

In addition, I explored Windows file and storage management by working with NTFS and ReFS file systems, disk and partition management, shared folders, NTFS permissions, share permissions, user profiles, password management, and access control. To improve the reliability of the environment, I configured an Additional Domain Controller, learned the concepts of Active Directory replication, and performed backup and recovery operations. Throughout the deployment, I also diagnosed and resolved common issues related to Active Directory, DNS, DHCP, Group Policy, authentication, and domain connectivity.

---

## About This Repository

This repository is a collection of the knowledge, practical implementation, and documentation I developed while building this Windows Server Administration lab. Rather than serving only as a step-by-step installation guide, it is intended to explain the technologies used in enterprise Windows environments and demonstrate how they are configured, managed, secured, and maintained.

Each technology is documented in its own Markdown file, providing a structured explanation of its purpose, architecture, components, configuration, administrative tasks, best practices, troubleshooting techniques, and, where applicable, the implementation steps performed in my lab environment.

The goal of this repository is to serve as both a personal learning portfolio and a technical reference for students, IT professionals, and recruiters who want to understand enterprise Windows Server administration and Active Directory infrastructure.
