# Active Directory Administrative Center (ADAC)

## What is ADAC?

**Active Directory Administrative Center (ADAC)** is a modern management tool used to manage Active Directory. It provides an easy-to-use graphical interface for creating and managing users, groups, computers, Organizational Units (OUs), and other Active Directory objects.

Compared to Active Directory Users and Computers (ADUC), ADAC offers additional management features and a more user-friendly interface.

**Shortcut Command:**

```cmd
dsac.exe
```

---

# Sections in ADAC

### Overview

The **Overview** page provides a summary of the selected Active Directory object and quick access to common administrative tasks.

---

### Local Domain

The **Local Domain** section displays the current Active Directory domain. From here, administrators can manage users, computers, groups, OUs, and other domain objects.

---

### Active Directory Administrative Center

This is the main workspace where administrators perform daily management tasks such as creating users, resetting passwords, moving objects, and managing Organizational Units.

---

### Global Search

The **Global Search** feature allows administrators to quickly find users, computers, groups, or other Active Directory objects without manually browsing through the domain.

---

### Task Pane

The **Task Pane** displays the available actions for the selected object. It allows administrators to create, delete, rename, move, enable, disable, or manage Active Directory objects.

---

### Windows PowerShell History

One useful feature of ADAC is the **Windows PowerShell History** pane. It automatically shows the PowerShell commands generated when performing tasks through the graphical interface, making it easier to learn PowerShell.

---

# What Can We Do in ADAC?

Using ADAC, we can:

- Create and manage user accounts.
- Create Organizational Units (OUs).
- Create Security and Distribution Groups.
- Reset user passwords.
- Unlock locked user accounts.
- Enable or disable user accounts.
- Move users and computers between OUs.
- Manage computer accounts.
- View and edit object properties.
- Perform Global Search.
- View the PowerShell commands for administrative tasks.

---

# Why is ADAC Used?

ADAC simplifies Active Directory management by providing a modern interface with advanced management features. It helps administrators perform common tasks more efficiently and also introduces PowerShell by displaying the commands used in the background.
